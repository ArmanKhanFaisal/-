# আয়াতস্রোত

HTML, CSS এবং Vanilla JavaScript দিয়ে তৈরি responsive Quran ও Hadith reading website starter.

## চালানোর নিয়ম
1. `index.html`, `style.css`, `app.js` একই ফোল্ডারে রাখুন।
2. ইন্টারনেট সংযোগসহ `index.html` খুলুন। সরাসরি file হিসেবে খুললে কিছু ব্রাউজারে API fetch সীমাবদ্ধ হতে পারে; VS Code-এর Live Server ব্যবহার করা ভালো।
3. কুরআনের আরবি পাঠ ও বাংলা অনুবাদ AlQuran Cloud API থেকে অনলাইনে লোড হয়। তাই সম্পূর্ণ কুরআনের পাঠের জন্য ইন্টারনেট লাগবে।
4. বুকমার্ক, ডার্ক মোড এবং সর্বশেষ পড়া সূরা একই ব্রাউজারের localStorage-এ থাকে।

## গুরুত্বপূর্ণ প্রকাশ-পূর্ব কাজ
- এই starter-এ ১১৪ সূরার তালিকা আছে, কিন্তু ইন্টারনেট ছাড়া সম্পূর্ণ কুরআন এমবেড করা নেই।
- অনলাইন API থেকে পাঠ্য আনা হয়; API/অনুবাদের সংস্করণ ও লাইসেন্স প্রকাশের আগে যাচাই করুন।
- হাদিস অংশে কয়েকটি উদাহরণমাত্র আছে, সম্পূর্ণ সংকলন নয়। প্রকাশের আগে নির্ভরযোগ্য প্রকাশনা/ডেটাসেট থেকে প্রতিটি হাদিসের আরবি, অনুবাদ, নম্বর, অধ্যায় ও সূত্র যাচাই করে পূর্ণ ডেটা যোগ করুন। কিছু উদাহরণে নম্বর/শব্দ যাচাইয়ের সতর্কতা রয়েছে।
- `localStorage` বুকমার্ক শুধুমাত্র ওই ডিভাইস/ব্রাউজারে থাকে; লগইন/সিঙ্ক নেই।
- ফন্টের জন্য Google Fonts ব্যবহার করা হয়েছে; প্রথমবার লোডে ইন্টারনেট লাগতে পারে।

## ফাইল
- `index.html`: page structure
- `style.css`: responsive styling and dark mode
- `app.js`: surah list, API loading, bookmark, search, sample hadith
